# 01: 实时输出携带代理参与实例归属

**What to build:** 实时输出消费者能够区分主代理、同名并发子代理和嵌套委派的输出，并据此建立代理层级。采用已确认的代理参与实例语义：每次独立委派拥有稳定身份，同一委派内多轮执行共享身份。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 每条新事件携带 run_id，task_id 继续用于输出流路由，两者不混用。
- [x] 代理产生的事件携带 agent_instance_id、parent_agent_instance_id 和 agent_name；主代理父身份为空，运行汇总事件允许没有代理身份。
- [x] 两个同名子代理并发执行时输出分别归属不同参与实例；嵌套委派指向具体父实例，名称不作为唯一标识。
- [x] 正文增量、工具调用、工具结果、错误及其他代理输出均正确归属，同一委派的多轮执行保持身份。
- [x] 元数据贯穿输出、Redis 写入与读取及 SSE，保留 type/delta 含义，不要求兼容历史数据。
- [x] 通过端到端测试验证并发同名委派、嵌套委派与运行汇总事件的 SSE 归属。

范围不包含 TUI 实现；恢复后的身份连续性由 04 完成。

## Comments

实现已完成：以独立委派 ID 标识多代理参与实例，具体父实例沿调度链传递；普通运行采用运行内主代理身份。输出装饰器统一附加归属，字段贯穿 Redis 与 SSE，运行汇总仅携带 run_id。

验证：Redis 往返、流式正文、工具调用及结果/错误、同名并发委派和嵌套委派的 SSE 端到端测试；`go test ./...` 通过。恢复、持久历史及生命周期仍由后续 ticket 实现。
