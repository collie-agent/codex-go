# 03: 通过生命周期事件展示代理状态

**What to build:** 实时消费者能够观察每个代理参与实例的创建与状态变化，包括没有正文输出的子代理，并可靠区分完成、失败和主动中断。

**Blocked by:** 01: 实时输出携带代理参与实例归属。

**Status:** resolved

- [x] 生命周期事件携带参与实例归属，通过完整输出与 SSE 链路可见。
- [x] 明确定义待执行、运行中、完成、失败、主动中断状态及合法转换，主代理与子代理均遵守契约。
- [x] 创建时可获得名称和父参与实例身份，即使子代理未产生正文，也可建立层级并观察终态。
- [x] 正常完成、业务失败、执行错误及主动中断分别产生符合实际语义的状态；同级任务因错误被取消时也有明确语义，不误报成功。
- [x] 进程突然消失或输出失败造成终态缺失时，不将缺失解释为完成，不承诺在不可写入时发出终态。
- [x] 状态契约允许恢复时原实例重新进入运行中，主动中断保持不可恢复语义；实际恢复链路由 04 完成。
- [x] 测试验证正常完成、业务失败、执行错误、主动中断和无正文子代理的 SSE 生命周期事件；记录状态协议供消费者使用。

范围不包含 TUI 实现。此票可与 02 并行，使用共同输出契约，避免另建专用传输或存储通道。
