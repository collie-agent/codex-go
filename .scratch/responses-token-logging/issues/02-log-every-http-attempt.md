# 02: 将 token 统计覆盖扩展到每次 HTTP 尝试

**What to build:** 在已有响应统计基础上，让每次实际发出的 Responses API HTTP 尝试都产生且只产生一条单行统计日志，包括 SDK 自动重试、HTTP 错误、网络错误和超时。用户可追踪全部尝试；有 usage 时保留实际数值，其余标记为 `unknown`，不估算消耗。

**Blocked by:** 01 — 打印已返回响应的 token 统计。

**Status:** ready-for-agent

## Acceptance criteria

- [x] 每次 HTTP 尝试记录一条统计，包含 SDK 内部自动重试及应用层重新请求；SDK 调用最终返回时不再重复记录同一尝试。
- [x] 每次尝试保留自身统计，不合并失败和成功重试的消耗，不增加代理运行或会话累计。
- [x] 保留票据 01 的四项 token 口径、未知值与零值区分、所有日志级别输出、单行格式和请求标识；可用的 response ID 与实际响应状态仍被保留。
- [x] SDK 完整读取的 HTTP 错误或非 completed 响应只要含可用 usage，仍打印实际值；SDK 未读取即丢弃的重试正文记录为 `unknown`，不得为统计额外读取；没有可用统计、响应无法解析、网络错误或超时的尝试，将对应数值打印为 `unknown`。
- [x] 无正常 response 状态时，日志中的请求结果可区分 HTTP 错误、网络错误和超时；不得因记录错误详情而暴露凭据或新增正文日志。
- [x] 生成 schema、校验工具消息等在 HTTP 尝试发生前失败的情况，不产生 token 统计日志。
- [x] 读取响应以记录统计不影响 SDK 的响应解析、重试条件与次数、取消、连接关闭及原有返回错误；记录失败不替换原有请求结果。
- [x] 在 HTTP 尝试边界、响应正文保留和避免重复记录等关键处添加注释。
- [x] 使用本地可控服务验证首次成功、失败后成功、重试耗尽，以及 HTTP 错误携带 usage 的情况；日志条数与实际 HTTP 尝试次数一致，各次统计互不混淆。
- [x] 使用可控传输验证网络错误和超时，验证原有错误与取消语义，以及请求前失败不产生统计；回归验证非 completed、工具调用和解析失败不重复记录。
- [x] 保持票据 01 的验收用例通过，并通过全量 Go 测试。

## Comments

- 用户已确认本票依赖 01。依赖原因：沿用并扩展前一票已经交付的 token 口径、日志格式及响应场景覆盖，最终统一到每次 HTTP 尝试的边界。


### 实现完成（2026-10-25）

- 经用户确认，在公开 Run / RunWithToolMessages + 本地 HTTP 服务、公开接口 + 可控 HTTP 传输两个边界验证。
- 将统计迁移到 SDK 每次尝试执行的 middleware，移除 SDK 调用返回后的重复记录；请求前校验失败不记录。
- 保留原响应字节、读取错误及原响应体 Close 行为，沿用前一票的统计口径及日志格式。
- 无 response 状态时区分 http_error_<code>、network_error、timeout、canceled 和 unknown；不新增正文或错误详情日志。
- 本地 HTTP 测试先复现重试及失败日志缺失，再加入实现并通过；验证首次成功、失败后成功、重试耗尽、HTTP 错误携带 usage 和无效响应。
- 可控传输测试验证网络错误、超时、取消、读取错误的原始错误链和响应体关闭，并检查请求前失败无统计。临时移除尝试层记录后，这些失败场景均因缺失日志而失败，恢复后通过。
- 票据 01 的非 completed、工具调用、输出解析失败、应用层再次请求、零值及未知值场景继续通过。
- 验证：`go test ./...`、`git diff --check`。

### 审查修复（2026-10-25）

- 移除 middleware 的预读取，改为随 SDK Read 收集字节、Close 时记录；SDK 未读取的重试正文记录 unknown，最终读取的 HTTP 错误仍保留 usage。
- SDK 返回后兜底关闭响应体，避免 context 提前退出导致泄漏；同一响应体只关闭和记录一次。
- 新增公开 Run 边界回归测试：慢速 500 正文不能阻止下一次成功重试；正文读取期间超时、响应头返回时取消均关闭原正文且只记录一次。测试在修复前均失败。
- 修复后验证：`go test ./internal/provider -count=1`、`go test ./...`、`go test -race ./internal/provider -count=1`、`git diff --check` 均通过。
