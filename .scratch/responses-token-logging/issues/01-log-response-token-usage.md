# 01: 打印已返回响应的 token 统计

**What to build:** 对每次模型调用返回的 Responses API 响应打印单行 token 统计，让用户在所有日志级别下都能查看该次请求的总输入、总输出、缓存命中输入和缓存未命中输入。覆盖任务分析、主代理、观察器、工具调用后的请求和输出纠错请求；不增加代理运行或会话累计。本票覆盖已返回响应，逐次 HTTP 尝试与请求失败记录由票据 02 扩展。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## Acceptance criteria

- [x] 每次模型调用返回的响应记录一次统计，包括非 completed 响应；工具调用、空输出和后续输出解析失败均不遗漏或重复记录。
- [x] 单行包含 task ID、调用标签（有则打印）、请求模型、response ID（有则打印）、响应状态及四项 token 统计，沿用现有日志输出位置。
- [x] `input_tokens` / `output_tokens` 使用服务端报告的总输入 / 总输出；`cached_input_tokens` 使用服务端报告的缓存命中输入；`uncached_input_tokens` 等于总输入减缓存命中输入，包括缓存写入的输入消耗。
- [x] 缺失或 null 的数值记录为 `unknown`，明确返回的零记录为 `0`。缓存明细缺失时命中与未命中均为 `unknown`，仍保留已知的总输入与总输出。
- [x] `info` / `error` 等所有日志级别均输出统计，不新增开关；保持既有上下文、响应文本及工具日志的行为。
- [x] 单条日志一次写入，避免并发日志交错；统计日志不新增请求正文、响应正文或凭据。
- [x] 日志处理不改变响应解析、工具调用、返回值或原有错误，关键的统计口径和未知值处理加注释。
- [x] 使用本地可控响应验证正常统计、部分命中、全命中、零命中、显式零、缺失/null usage、缺失/null 缓存明细，以及非 completed、工具调用和解析失败时的日志。
- [x] 验证两种现有日志级别均保留统计与可用的请求标识，相关测试和全量 Go 测试通过。
