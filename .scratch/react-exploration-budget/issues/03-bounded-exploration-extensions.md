# 03: 有限探索延期与拒绝后的收束

**What to build:** 模型对阻止修改的具体信息缺口申请有限探索延期，运行时自动审批；次数或总预算不允许时拒绝，并要求改选实施或无法完成，不能反复申请以维持调查。

**Blocked by:** 01：探索阈值、延后分类与阶段决策。

**Status:** ready-for-agent

- [x] 申请必须包含具体缺口、为何阻止修改、定向调查操作以及缺口补齐的判定条件；缺失字段不得获批。
- [x] 运行时检查字段、剩余次数和总预算后自动审批，不逐次询问用户，也不增加一次模型合理性审查。
- [x] 默认每次增加四轮探索额度，最多两次，初始默认额度下累计最多二十轮探索；新证据不自动续期，批准不清零已有消耗。
- [x] 延期额度和次数可在配置文件设置并逐字段继承；额度必须为正整数，次数允许为零，省略和零区分，非法值启动时报错。
- [x] 延期不得扩大总预算，也不得侵占现有失败收尾预留；剩余预算不足时拒绝，不静默发放超额额度。
- [x] 申请决策轮不执行混入工具，获批状态与次数先保存，再允许定向调查；保存失败不得继续。
- [x] 超过次数或总预算不足时明确反馈拒绝原因，要求改选实施或无法完成；反复无效申请受既有决策纠错上限约束，不另开启无限纠错循环。
- [x] 延期次数、获批额度及拒绝原因写入执行实例状态与日志，基本恢复不重复授予同一次延期。
- [x] 通过真实 ReAct 循环验证一次获批调查补齐信息、零次延期、连续延期耗尽、缺字段拒绝、拒绝后有界失败及总预算不足。获批额度始终与实际调查计费相符。
