# 05: 将独立配置接入 ReAct 与内部代理

Status: needs-info

**What to build:** 各模型调用使用其代理类型的有效配置，观察器不再复用 ReAct 独立配置。

**Blocked by:** 04。

- [ ] CLI 与 agent-server 迁移到新配置加载入口，保持现有启动、任务、工作目录和退出语义。
- [ ] ReAct 使用 react 的模型、提示词和允许工具；沿用工具暴露及执行端拒绝机制。
- [ ] ReAct 触发观察器时使用 observe 配置，观察器追加自己的自定义提示词。
- [ ] 现有任务分析器调用接口支持 task_analyzer 配置，不新增 CLI 调度。
- [ ] 每个代理将有效自定义提示词追加到自己的内置提示词后；独立提示词不与 base 内容拼接，显式空值仅保留内置提示词。
- [ ] 任务分析器和观察器始终不暴露、不执行工具；保持现有异常工具调用拒绝语义。
- [ ] 使用可控模型响应验证三个处理器的实际请求，包括观察器与 react 使用不同模型和提示词、未配置内部代理回退 base、工具能力边界。
- [ ] 保留用户已有任务分析器改动，关键配置传递边界加注释。
