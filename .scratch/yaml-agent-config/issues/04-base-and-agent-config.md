# 04: 解析 base 与按代理类型划分的独立配置

Status: needs-info

**What to build:** 用新 YAML 格式解析共享设置及代理独立设置，输出经过全量校验、可供各处理器使用的配置。

**Blocked by:** None。票据 01–03 已完成；等待整体设计确认。

- [ ] 顶层支持 `name`、必填 `base`、可省略 `agents`，拒绝旧格式；启动类型仍仅支持 `react`。
- [ ] 独立类型支持 `react`、`task_analyzer`、`observe`，空配置映射及未配置类型均回退 base。
- [ ] 区分省略与显式空值；三个设置逐项回退，LLM 整块替换，工具列表整块替换，自定义提示词替换 base 内容。
- [ ] 拒绝显式 null；严格校验字段、类型、工具、输出格式和单 YAML 文档；沿用 LLM 默认值及密钥规则，错误不泄露密钥。
- [ ] base 包含完整有效 LLM；启动校验所有独立块，包括未使用代理的模型与密钥。
- [ ] 两个内部代理最终工具集合为空；独立配置显式非空工具列表报错，base 工具不赋予它们工具能力。
- [ ] 配置解析结果可按类型获取，避免不同代理修改共享配置产生串扰；关键行为加注释。
- [ ] 测试覆盖上述边界，并迁移旧加载测试夹具。
