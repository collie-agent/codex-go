# 05: 命令验证与进程等待纳入有界进度控制

**What to build:** 命令验证及进程会话等待受独立进度和截止时间约束，既允许修复后重新测试和合理轮询，也能从重复验证或无限等待中恢复并收尾。

**Blocked by:** 01：文件重复读取触发有界恢复；02：执行实例恢复沿用进度状态与预算

**Status:** resolved

- [x] 命令证据结合命令、相关工作区版本、退出状态和结果指纹；执行工具或使缓存失效本身不自动证明取得进展。
- [x] 实际修复后允许重新执行相同验证命令，保留已有失败重试规则；重复无变化验证纳入停滞恢复。
- [x] 进程会话证据包含会话标识、输出 cursor、状态及等待时间；合理等待不因若干次空轮询就被误判失败。
- [x] 会话使用可配置的等待截止时间；无输出或持续输出都不能无限延长等待，超时进入恢复或明确收尾。
- [x] 进程会话在归属执行结束后失效，恢复不继承旧会话；无法确认结果的调用仍按 ADR-0004 处理，禁止自动重跑。
- [x] 端到端覆盖修复后重测、重复验证无变化、合理轮询、输出 cursor 推进、无输出超时及持续输出超时；验证预算与恢复后的收尾行为。
