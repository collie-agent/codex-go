# 02: 执行实例恢复沿用进度状态与预算

**What to build:** 代理运行恢复时延续原执行实例的进度与预算，避免反复恢复刷新轮数；预算耗尽前进行有界收尾，保存可信的未完成结果。

**Blocked by:** 01：文件重复读取触发有界恢复

**Status:** resolved

- [x] 运行检查点保存执行实例的已用轮数、停滞计数、恢复阶段、恢复次数及有界证据索引；同实例恢复沿用，新执行步骤独立初始化。
- [x] 模型决策前扣除并保存轮次预算，不能只根据工具历史推算；完全去重和无工具的决策轮次也不能在恢复后免费重放。
- [x] 读取旧检查点时采用明确兼容策略，不把缺少历史字段解释为已经确认的进度或完成。
- [x] 总预算为恢复和收尾预留空间；收尾最多请求一次模型总结，请求失败时根据已保存记录生成已有变更、验证结果、未完成项及停止原因，不编造成功。
- [x] 收尾保存检查点并返回可识别的失败结果或错误，避免仅返回零值导致已有执行信息丢失。
- [x] 保留工具执行前登记、执行后保存的顺序；工具执行结果未知时遵守 ADR-0004 停止自动执行，不借恢复自动重跑。
- [x] 通过跨检查点恢复的端到端测试证明预算不刷新、停滞状态不丢失、新执行步骤隔离，且结果未知的调用不被重复执行。
