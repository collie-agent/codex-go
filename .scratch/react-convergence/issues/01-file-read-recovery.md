# 01: 文件重复读取触发有界恢复

**What to build:** 文件调查连续没有新增证据时，下一轮收到基于实际结果的恢复提示，能够转向修改、验证并完成；恢复仍无进展时明确失败。进度观察独立于精确去重与异步事实观察，由主循环同步驱动。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 文件工具在读取时采集规范化路径、内容版本和实际返回范围，元数据与返回内容来自同一次读取；版本未知时不得直接断言重复。
- [x] 工具可并发执行，主循环在本批结果收齐后、下一轮模型决策前同步生成 BatchEvidence 并更新进度状态，不依赖异步 ObserveProcess。
- [x] 按同版本文件的实际范围覆盖判断新增证据；仅增加 limit 而未新增内容不算进展，未读范围和文件变化后重读允许继续。
- [x] 完全被去重的批次也计入观察；混合批次根据整体新增证据判断，不因存在一个实际执行的调用而清零。
- [x] 连续无新增证据阈值可配置，初始候选值为四批；恢复提示包含确定的重复摘要、当前目标及可获取的未满足完成条件、证据引用和剩余预算，不强制修改或宣告成功。
- [x] 恢复窗口及恢复总次数有上限；取得新证据不解除总体轮数约束；新增证据不等于任务完成。
- [x] 端到端模拟重复读取后收到恢复反馈，随后修改、验证并完成；另覆盖恢复无效时有界失败，以及只读任务持续获取新证据时正常继续。
