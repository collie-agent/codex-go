# 06: 计划步骤续接与模式切换恢复

**What to build:** 用户恢复计划运行时继续未完成步骤自己的 ReAct 实例，跳过完成步骤；升级计划模式及完成标准更新不会因恢复重复生效。

**Blocked by:** 05 — 普通 ReAct 持久化与恢复

**Status:** ready-for-agent

- [ ] 计划步骤持久化关联稳定执行实例，保留 step_id、revision、position、任务及完成标准；不同步骤原生工具历史互相隔离。
- [ ] 未完成步骤恢复自己的实例及工具结果，已完成步骤及证据不重新执行；未知工具结果沿用停止规则。
- [ ] 步骤状态、观察、完成证据及对应完整实例结果原子提交；全部步骤结果已保存而根运行未收尾时，不调用 planner 或 executor，直接收尾返回。
- [ ] 完成标准控制工具的状态变更与结果一致提交；恢复不能重复生成或应用已确认标准。
- [ ] ReAct 升级计划执行时模式、交接状态及对应控制调用结果一致保存；升级前历史仅作交接背景，不重复注入各步骤原生消息。
- [ ] 覆盖控制工具提交前后、计划步骤执行中、步骤完成后及最终收尾前的故障窗口，验证身份、模式、证据及工具调用次数。
- [ ] 通过 CLI/服务入口验证计划恢复和动态升级恢复，并更新相应使用说明。
