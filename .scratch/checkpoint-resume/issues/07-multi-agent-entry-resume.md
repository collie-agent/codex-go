# 07: 多代理入口执行实例恢复

**What to build:** 无子委派的多代理运行可以恢复其入口执行实例，保留工具进度和完整节点输出，并正确返回成功或终态业务失败。

**Blocked by:** 05 — 普通 ReAct 持久化与恢复

**Status:** ready-for-agent

- [ ] 为入口委派建立持久化身份及稳定执行实例关联；局部任务标识与根 run_id 分离，工具记录始终可归属根运行及独立上下文。
- [ ] 多代理入口复用共享 ReAct 工具持久化及恢复路径，续接原实例，不因重新进入运行而重建上下文身份。
- [ ] 保存完整 MultiAgentResult 和实例状态；根业务失败写入 failed 及失败类型，不误标 completed；重复 resume 直接返回已确认终态结果。
- [ ] 入口完成标准持久化且恢复不重新生成；节点结果已保存、根运行未收尾时不重新调用模型或工具。
- [ ] 执行故障与业务失败分别处理，未知工具结果阻止继续；保持原有有子委派路径可运行，委派恢复由任务 08 完成。
- [ ] 验证无子委派场景在 CLI/服务入口的成功、业务失败、执行故障及崩溃恢复；断言根身份和局部身份不混淆，原有多代理行为不回归。
