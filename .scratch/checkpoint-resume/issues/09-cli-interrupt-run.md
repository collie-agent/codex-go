# 09: CLI 主动中断整个运行

**What to build:** 用户在 CLI 按 Ctrl-C 时主动结束整个运行，保存可确认进度；三种模式均停止调度，interrupted 运行不能 resume。

**Blocked by:** 06 — 计划步骤续接与模式切换恢复；08 — 多代理委派与报告恢复

**Status:** ready-for-agent

- [ ] 持久化 interrupted 运行状态，显式区分主动中断与执行故障；Ctrl-C 进入统一根运行中断流程。
- [ ] 停止新模型、工具和子任务调度，取消全部正在执行的实例及工具，等待必要收尾；已完成实例结果保留，无法确认的工具结果标注未知，不宣称副作用已撤销。
- [ ] 执行 context 取消后仍能完成可行的结果与根状态持久化；保持持锁连接约束，锁失效时不绕过互斥写入；输出实际保存成功或失败的状态。
- [ ] 处理与正常完成竞争的中断请求，避免已确认终态被延迟中断覆盖；重复中断不重复收尾。
- [ ] interrupted 根运行拒绝 resume；同会话下一次新输入创建新 run，旧历史加载由任务 11 完成。
- [ ] 请求断开、超时及服务退出不自动解释成用户主动中断；首版只中断根运行，不提供单 worker 中断。
- [ ] 覆盖模型请求中、并发工具中、计划步骤中、多代理等待子任务中及最终完成竞争时的 Ctrl-C；验证无新调度、结果保留、锁释放及不可 resume。
- [ ] 更新 CLI 中断行为及恢复区别的说明，为服务入口提供可复用的运行中断能力。
