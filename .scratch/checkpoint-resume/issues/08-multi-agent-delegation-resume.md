# 08: 多代理委派与报告恢复

**What to build:** 用户恢复多代理运行时继续原委派图和等待关系，复用完成的子任务结果，处理未完成子任务，父节点不重复委派或丢失报告。

**Blocked by:** 07 — 多代理入口执行实例恢复

**Status:** ready-for-agent

- [ ] 持久化稳定委派身份、父子关系、声明顺序、节点输入、等待批次、子报告、调度位置及执行实例关联；不能复用进程内计数作为恢复身份。
- [ ] 节点完整输出与由其产生的子委派安排原子提交后才启动子任务；重入复用已登记委派，不重复创建子任务。
- [ ] 各子任务复用共享实例恢复路径，结果分别持久化；恢复保留已完成兄弟任务，只续接未完成实例，未知结果阻止相应恢复。
- [ ] 子报告齐备后父节点创建一个新的独立执行实例；登记后崩溃仍复用该实例，不能重复消费同批报告创建多个后续实例。
- [ ] 保持报告声明顺序、上游报告语义及每次独立调用的上下文隔离；支持嵌套委派，返回 caller 不创建新的 caller 子任务。
- [ ] 子业务失败作为报告交父节点；基础设施故障停止整棵运行，保留已确认子结果，根业务失败沿用终态结果返回规则。
- [ ] 故障注入覆盖委派登记前后、兄弟部分完成、子报告全部完成、父后续实例登记及结果保存边界，断言不重复委派、不重跑已完成子任务、不丢报告。
- [ ] 通过实际运行入口验证嵌套及并发多代理恢复；更新使用说明，不引入配置兼容性或预算计数恢复机制。
