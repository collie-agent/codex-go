# MCP 文件工具

Status: ready-for-agent

## 已确认的要求

- 使用 `github.com/modelcontextprotocol/go-sdk/mcp` 提供 `list_dir`、`read_file`、`glob`、`grep`、`apply_patch`。
- `list_dir` 通过 `find` 实现；`read_file` 通过 `sed` 实现；`glob` 和 `grep` 通过 `rg` 实现。
- 启动时指定工作目录，相对路径以该目录为基准。只允许访问工作目录内的文件，符号链接同样遵守此范围。
- `read_file.offset` 是从 1 开始的起始行，默认 1；`limit` 是最多读取的行数，默认 200；结果附带行号。
- `glob` 和 `grep` 默认遵循 `.gitignore`，搜索隐藏文件但排除 `.git/`；提供参数允许搜索被忽略的文件。
- `apply_patch` 用 Go 移植 `/home/xzp/workspace/atom-mcp` 的 unified diff 解析和匹配规则，支持新增、修改、删除，不支持重命名；仅处理 UTF-8 非二进制普通文件，拒绝符号链接目标，保留错误码 1201–1206。
- 所有工具共用启动时指定的工作目录，不提供工具级 `cwd` 参数；补丁中的路径以启动工作目录为基准。
- 提供工具注册函数和 stdio 启动入口，通过启动参数指定工作目录。
- `list_dir` 默认只列直接子项，包含隐藏文件、排除 `.git`；支持 `depth`，返回相对工作目录的路径和条目类型，不跟随符号链接递归。
- `glob` 接受 `pattern` 和可选 `path`，只返回文件；匹配以搜索目录为基准，结果路径相对工作目录，按路径排序。
- `grep` 默认正则搜索且区分大小写，支持字面搜索、忽略大小写和 glob 文件过滤；每条结果包含路径、行号、匹配行文本。
- 工具返回结构化结果及可读文本；列表和搜索默认最多 200 条，允许调整；单次响应最多 1 MiB，截断时明确标记。
- 命令默认超时 30 秒，支持请求取消，使用参数数组直接执行命令。
- 补丁在解析、路径验证或匹配失败时不修改任何文件；写入阶段失败不回滚已经完成的修改，错误结果明确报告已完成和失败的路径。
- `list_dir`、`glob`、`grep` 支持从 0 开始的 `offset` 和默认 200 的 `limit`，返回 `truncated` 和 `next_offset`；结果顺序固定，文件变化可能影响跨请求分页。
- 达到 1 MiB 响应上限时明确截断；`read_file` 返回下一次读取的行号。
- `read_file` 只读取 UTF-8 非二进制普通文件；允许读取最终目标仍在工作目录内的符号链接；起始行超过 EOF 时返回空结果，`offset<1` 或 `limit<1` 返回参数错误。
- 启动必须提供 `--workspace`，启动时检查目录以及 `find`、`sed`、`rg`，失败则退出；stdio 日志写入 stderr。
- 搜索无匹配返回成功的空列表；执行失败返回 MCP 工具错误。

## 参数契约

参数类型：路径、模式和补丁为字符串；`depth`、`offset`、`limit` 为整数；开关为布尔值。下表中未标默认值的参数必填，标为可选的参数允许省略。

| 工具 | 参数 |
| --- | --- |
| `list_dir` | `path="."`、`depth=1`、`offset=0`、`limit=200` |
| `read_file` | `path`、`offset=1`、`limit=200` |
| `glob` | `pattern`、`path="."`、`include_ignored=false`、`offset=0`、`limit=200` |
| `grep` | `pattern`、`path="."`、`glob`（可选文件过滤）、`literal=false`、`ignore_case=false`、`include_ignored=false`、`offset=0`、`limit=200` |
| `apply_patch` | `patch` |

- 不提供工具级 `cwd`。
- `grep.path` 可以是文件或目录；`list_dir.path` 和 `glob.path` 必须是目录。
- `depth>=1`；列表和搜索的 `offset>=0`；读取的 `offset>=1`；所有 `limit>=1`。
- 可调整 `limit`，响应仍受 1 MiB 上限约束。

## 路径与顺序

- 启动参数 `--workspace` 必填，必须指向存在的目录；所有工具共享该目录。
- 工具只接受相对工作目录的路径，拒绝绝对路径；允许解析后仍在工作目录内的 `..`。
- 补丁路径遵循参考实现的规则，包括去除 git 的 `a/`、`b/` 前缀和使用 `/dev/null` 表示新增或删除。
- `list_dir.depth=1` 只列直接子项，不包含搜索目录自身；深度相对指定目录计算。
- `list_dir` 可以列出符号链接条目，不跟随链接递归；`glob` 和 `grep` 不跟随符号链接；读取链接的最终目标必须仍在工作目录内；补丁拒绝符号链接目标。
- 返回路径相对工作目录；目录列表和 glob 按路径排序，grep 按路径、行号排序。
- 对固定顺序的结果先应用 `offset`，再应用条数和响应字节上限；工作目录变化时不保证跨请求分页快照一致。

## 返回契约

- 结构化结果是唯一数据来源，可读文本从结构化结果生成。
- `list_dir`、`glob`、`grep` 返回 `items`、`truncated`、`next_offset`。目录条目包含路径和类型，glob 条目包含路径，grep 条目包含路径、行号和匹配行文本。
- `read_file` 返回带行号的 `lines`、`truncated`、`next_offset`；读取的下一偏移是行号。
- `next_offset` 在结果结束时为 `null`；发生条数或字节截断时标记 `truncated=true`，提供继续读取的偏移。
- 响应上限是完整 MCP 工具响应的 JSON 字节数，最多 1 MiB；结构化结果和可读文本都计入。
- 单条记录超过响应上限时返回明确错误，不能返回无法前进的分页结果。
- `apply_patch` 成功结果包含相对工作目录的 `affected` 路径；写入阶段失败时报告已完成和失败的路径。
- 空目录、搜索无匹配和读取偏移超过文件末尾均返回成功的空结果。
- 参数错误和执行错误返回 MCP 工具错误；补丁保留参考错误码：1201 无效补丁、1202 无效路径、1203 冲突或目标缺失、1204 目录目标、1205 符号链接目标、1206 写入失败。

## 执行与启动

- 使用 `github.com/modelcontextprotocol/go-sdk/mcp`，提供注册函数和 stdio 服务入口。
- 必须使用 `find`、`sed`、`rg` 实现已经指定的操作，以参数数组直接执行，不经过 shell 拼接。
- 启动检查工作目录和三个命令，缺少依赖时退出；stdio 日志写入 stderr。
- 启动参数 `--timeout` 默认 `30s`，统一控制各工具执行，支持请求取消。
- 补丁开始写入后发生超时或取消，按写入阶段失败规则报告完成情况，不承诺回滚。

## 参考实现事实

- `atom-mcp` 接受标准 unified diff，支持新增、修改、删除，不支持重命名。
- 先检查所有路径并在内存中应用所有补丁，再开始写入；写入阶段失败不会回滚已经写入的文件。
- 匹配依次使用精确文本、忽略行尾空白、忽略首尾空白、有限标点归一化；按顺序向前寻找匹配，容忍过时行号。
- 补丁仅处理 UTF-8 非二进制普通文件，拒绝符号链接目标。
- 错误码为 1201–1206，成功返回相对工作目录的受影响路径。
- 来源：`/home/xzp/workspace/atom-mcp/src/atom_mcp/tools/apply_patch.py` 和 `docs/adr/0005-deterministic-patch-hunk-matching.md`。

- 第二轮：用户确认注册函数与 stdio 入口、目录递归、glob 和 grep 接口、输出上限与命令执行约定。

- 第四轮：用户确认完整参数表、相对路径和结果顺序、响应格式与字节上限、统一超时配置。
