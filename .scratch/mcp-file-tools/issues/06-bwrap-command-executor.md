# 新增基于 bwrap 的内部命令执行器

Status: ready-for-agent

用户已最终确认完整设计；Q1–Q14 无待定项，可按规格实施。

## 目标

在 `internal/mcp/exec.go` 实现独立的内部命令执行器。现有文件工具不接入，不新增 MCP 工具。完整契约以 [规格](../spec.md) 的“新增命令 sandbox”章节和 [安全边界 ADR](../../../docs/adr/0002-command-sandbox-boundary.md) 为准。

## 验收条件

- 入口仅允许规格中的 11 个命令名；拒绝任意可执行路径、shell 字符串及独立 cwd；子进程允许执行其他程序，但同样受 sandbox 边界约束。
- Workspace 根目录可读写，外部用户数据不可见；显式配置的外部运行时目录只读，隔离临时目录、HOME 与缓存。
- 受控 PATH 不包含 Workspace；清理继承环境，不传递宿主凭据、代理环境或 SSH agent。
- 强制规格要求的命名空间隔离，禁网并移除 capabilities；无宿主 socket 或额外文件描述符泄漏。
- 对危险的 Workspace 和运行时根目录配置执行规格规定的拒绝规则；符号链接规范化后的目录也须遵守相同规则。
- bwrap 缺失、平台或隔离能力不支持及 sandbox 创建失败均明确报错，不回退宿主执行。入口命令按需检查。
- 非交互执行；输出分别捕获、合计最多保留 1 MiB，截断后继续排空；普通非零退出码与启动失败、取消、超时可区分，错误时保留已捕获输出。
- 默认 30 秒超时；正常退出、超时、取消均清理完整进程树，不能由后台子进程延长调用或跨调用存活。
- 文档明确第一版没有 CPU、内存、进程数或磁盘配额。
- 在挂载边界、命令解析、输出排空和进程树清理等关键位置添加注释。
