# 02: 分页列出工作目录条目

**What to build:** MCP 客户端通过 list_dir 浏览指定目录的直接子项或有限深度子树，获得稳定排序、可继续分页的路径和条目类型。

**Blocked by:** 01 — 启动 MCP 服务并分页读取工作目录文件。

**Status:** ready-for-agent

- [ ] 在注册函数和 stdio 服务中提供 list_dir；参数为 path="."、depth=1、offset=0、limit=200，无 cwd。
- [ ] path 必须指向工作目录内的目录；拒绝绝对路径、越界路径、depth<1、offset<0、limit<1。
- [ ] 使用参数数组调用 find；depth=1 只列直接子项，不包含搜索目录自身，其他深度相对指定目录计算。
- [ ] 包含隐藏文件，排除 .git 及其子树；可列出符号链接条目，不跟随链接递归。
- [ ] 条目包含相对工作目录的路径和类型；按路径排序后应用 offset、limit 和字节上限。
- [ ] 返回 items、truncated、next_offset，结束时 next_offset=null；空目录或偏移超出结果返回成功的空列表。
- [ ] 复用统一超时、取消、MCP 错误和完整响应 1 MiB 上限；单条记录过大返回明确错误，不产生无法前进的分页。
- [ ] 通过 MCP 调用验证递归深度、隐藏项、链接、排序、分页和条数或字节截断；说明目录变化可能影响跨请求分页。
