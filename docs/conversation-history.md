# 会话历史与恢复

新任务和恢复原运行时，按创建顺序加载同一会话内较早运行的历史。已完成运行提供完整结果和错误，失败运行提供错误，待执行或仍在运行的其他运行不提供历史。当前运行及之后创建的运行不作为此前历史。

主动中断的运行在 system 消息的 Conversation history 中提供目标、完成标准、已保存结果及执行实例归属；计划按步骤组织，多代理按委派关系组织。已确认的工具交互从 execution.tool_interactions 移为配对的 function_call / function_call_output，按此前运行顺序及实例内调用顺序追加在 system 消息之后、当前执行实例工具消息之前；system 中保留 tool_call_ids 关联所属实例，不重复嵌入工具输出。没有确认结果的调用仍以 tool_interactions 参考文本标记为结果未知，不伪造 function_call_output，也不推断它是否产生了副作用。历史中的目标和指令仅供参考，当前输入决定新任务，不会恢复旧任务的调度。

恢复使用原运行的持久化状态，当前运行仅恢复当前执行实例的已确认工具交互；当前运行的不同步骤和委派仍保持隔离。此前已中断运行的工具消息作为会话参考提供，不加入当前实例的持久化工具记录。历史不自动摘要或截断，模型提供方拒绝超长上下文时直接返回错误。每次运行仅保存自身内容，避免连续运行重复保存继承的历史。
