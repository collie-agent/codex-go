# 会话历史与恢复

新任务和恢复原运行时，按创建顺序加载同一会话内较早运行的历史。已完成运行提供完整结果和错误，失败运行提供错误，待执行或仍在运行的其他运行不提供历史。当前运行及之后创建的运行不作为此前历史。

Conversation history 作为独立的 user 消息，位于 system 消息之后、所有原生工具调用和结果之前。system 仅保留指令、技能索引和输出约束。历史中的目标和指令仅供参考，当前输入决定任务。

主动中断的运行在 Conversation history 中提供目标、完成标准、已保存结果、执行实例归属及工具交互；计划按步骤组织，多代理按委派关系组织。已确认的调用和结果作为 Markdown 引用数据保留，不再重放为 function_call / function_call_output。没有确认结果的调用仍标记为结果未知，不伪造结果，也不推断它是否产生了副作用。主动中断仍结束原运行，后续输入创建新运行。

恢复使用原运行的持久化状态，当前运行仅恢复当前执行实例的已确认工具交互，并在本次恢复期间将这些交互固定为 Conversation history 中的引用数据；当前运行的不同步骤和委派仍保持隔离。恢复后新增的工具交互仍使用原生 function_call / function_call_output，位于历史之后、最新任务状态之前。此前已中断运行的工具交互作为会话参考提供，不加入当前实例的持久化工具记录。恢复记录保留在当前实例的持久化工具记录中，用于去重、回读和进度核对；缺少确认结果仍在任何模型请求前停止恢复。此前运行的历史不自动摘要或截断；当前执行实例的恢复交互沿用原有执行上下文压缩机制，摘要覆盖的批次从历史消息视图中移除，原始记录仍可回读。模型提供方拒绝超长上下文时直接返回错误。每次运行仅保存自身内容，避免连续运行重复保存继承的历史。
