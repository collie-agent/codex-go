# ReAct 恢复工具交互并保留结果不确定性

ReAct 恢复保留原运行及已确认的工具调用和结果，取代 ADR-0003 中从原目标重新开始的规则，避免丢失执行进度。工具执行前登记调用、执行后保存结果；缺少结果时停止自动执行，不假定工具未执行或依赖所有工具自行保证幂等，因为外部副作用与数据库写入无法统一原子提交。

用户主动中断结束原运行，后续输入创建新运行；会话历史按运行状态继承，且各运行只保存自身产生的内容，避免递归复制历史。

该机制统一用于普通 ReAct、计划执行和多代理，以稳定的执行实例隔离各自的工具历史；计划未完成步骤续接原实例，多代理另行持久化委派关系与调度进度。仅保存工具历史无法恢复上层调度，因而接受额外持久化成本，以避免重复执行已经完成的子任务。
