# 在运行时约束修改任务的探索预算

ReAct 的停滞检测会因新证据而重置，提示词要求及时实施也不能约束持续获得新信息但始终不修改的行为。因此，对具有代码修改目标的执行实例增加独立探索预算，并在阈值处由运行时要求可校验的实施、有限延期或无法完成决策；实施交接必须明确修改目标、已有证据和下一项操作。

预算与阶段状态归属于执行实例，恢复不刷新额度，继续遵循 [ADR-0004](0004-react-tool-history-resume.md) 的工具结果不确定性边界。接受额外的持久化阶段与决策协议成本，以换取可执行的探索上界；获得新证据不能续期，调用 exec 不能直接证明完成了修改。纯分析任务不要求修改，模型可在取得上下文后判断任务类型，不强制第一轮分类。
