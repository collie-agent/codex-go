# 按执行边界恢复代理运行

恢复决策已由 [ADR-0004](0004-react-tool-history-resume.md) 取代，包括计划未完成步骤改为恢复自身 ReAct 进度。

Checkpoint / resume 保留原 run 及目标，计划执行跳过已完成步骤并从头执行未完成步骤；普通 ReAct 从原目标重新开始，不保存逐轮消息与工具调用位置，也不产生执行步骤记录。相对于逐工具调用恢复，这减少了持久化执行上下文的要求，但可能重复执行已产生副作用、尚未写入 checkpoint 的工具操作；工具自行保证幂等，恢复流程不引入人工确认。

每步完成时原子保存步骤状态及完整执行结果。若进程在最后一步完成后、运行最终收尾前退出，恢复直接使用已保存结果结束运行，避免重新调用模型或工具。具体契约见[功能规格](../../.scratch/checkpoint-resume/spec.md)。
