# 进程会话归创建它的执行所有

为支持 agent 启动服务后逐步验证，新增显式的启动、轮询和停止工具，扩展 [ADR-0002](0002-command-sandbox-boundary.md) 中“不保留后台任务”的约定；同步 `exec` 的生命周期保持原有规则。进程会话归创建它的 ReAct 执行所使用的 MCP 连接所有，执行结束或连接断开时清理，不保留到后续步骤、委派或恢复，避免恢复工具历史时将已失效的进程身份误认为仍在运行。

接受恢复后必须重新启动服务的成本，换取明确的资源归属和清理边界；沿用每个会话独立的沙箱、宿主网络授权及进程树清理，不提供持久后台服务托管。停止先发送 SIGTERM 再强制清理，并等待沙箱 init 退出；会话日志及保留会话数有上限，同步 `exec` 仍完整返回输出。
