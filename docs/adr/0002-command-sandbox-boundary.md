# 命令 sandbox 以进程树资源访问为边界

新增内部命令执行器使用 bwrap 隔离进程树；命令白名单只限制入口，允许 Python、npm 等启动其他程序，以支持解释器和项目脚本。整个进程树可以读写 Workspace，但禁止访问外部用户数据，并默认完全禁网；运行必需的系统文件只读暴露，临时目录独立隔离。后续不得将入口白名单解释为对子进程可执行程序的完整限制。

此边界仅适用于新增执行器，现有文件工具不接入。工作区外的额外运行时目录由宿主显式配置并只读挂载，入口从受控 PATH 解析；不继承宿主凭据环境或 HOME。隔离不可用时拒绝执行，不回退宿主执行。命令退出、超时或取消均清理整个 sandbox，不保留后台任务。

网络命名空间不能阻止通过挂载目录中的 pathname Unix socket 连接宿主服务，因此额外使用子进程继承的 seccomp 过滤器禁止创建 Unix socket，并禁止 `io_uring`、旧式 `socketcall` 和非本机 ABI 绕过过滤。匿名 `socketpair` 仍可用于内部 IPC；依赖命名 Unix socket 或这些被禁止接口的项目任务会失败。过滤器无法安装时拒绝执行。

第一版只限制执行时间和捕获输出，没有 CPU、内存、进程数和磁盘配额；用户接受超时前资源耗尽的可能性。此决策不构成承载恶意代码的完整资源隔离方案。具体契约见 [MCP 文件工具规格](../../.scratch/mcp-file-tools/spec.md)。

宿主默认运行时策略额外只读暴露程序的 GOROOT（含 bin/go 的有效目录），使 Go 工具可直接使用；不从继承的 PATH 发现工具链。其他工作区外运行时仍需显式配置。GOROOT 不存在时不添加挂载，保持其他工具可用。

Go 离线依赖：启动时读取宿主 Go 的 GOMODCACHE，将存在且通过目录边界校验的缓存只读挂载到 `/run/go-mod-cache`，并设置沙箱 GOMODCACHE。沙箱 GOPROXY=off、GOSUMDB=off、GOTOOLCHAIN=local；构建缓存仍位于隔离临时目录。请先在宿主运行 `go mod download` 预填充项目依赖，再启动或重启服务；缺失依赖不会自动下载。不会挂载整个 GOPATH 或宿主 HOME。


宿主运行时自动发现（显式开启）：默认仍不继承宿主 PATH。启用 `--discover-host-commands` 后，初始化阶段根据配置的入口白名单，对受控 PATH 中缺少的程序从宿主 PATH 解析，校验真实目录后只读挂载并加入受控 PATH。白名单可通过重复的 `--exec-command` 替换内置默认值；工具调用不能改变发现策略。拒绝工作区内入口、工作区祖先、整个 HOME 和受保护目录。Python 虚拟环境入口以 `pyvenv.cfg` 识别，挂载其完整环境；其他复杂运行时依赖继续通过显式目录授权。此项扩展以上“其他运行时仍需显式配置”的策略：开启发现本身构成宿主对符合校验的运行时目录的授权，不改变离线和只读边界。


宿主网络及环境显式授权：新增 `--exec-network none|host`（YAML 顶层 `exec_network`）和可重复的 `--exec-env NAME`（YAML 顶层 `exec_env`）。默认仍使用独立网络命名空间且不继承宿主凭据环境；`host` 显式省略 `--unshare-net`，命令进程树共享宿主网络，使测试可访问 Docker 发布的 MySQL TCP 端口。此授权开放整个宿主网络，不提供按地址或端口的限制；Unix socket/seccomp、文件挂载和进程清理边界不变。环境授权仅保存变量名，在执行器初始化时解析已设置的宿主值；不继承其余环境，保留执行器管理的环境变量。命令行显式值覆盖 YAML，新建与恢复、进程内与外部 MCP 共用策略，工具调用不能改变授权。

`host` 模式额外将宿主 `/etc/resolv.conf` 的真实目标只读挂载到沙箱同一路径，避免指向 `/run` 的符号链接因沙箱私有 tmpfs 而失效。无法解析宿主 DNS 配置时拒绝执行并返回沙箱启动错误；默认及 `none` 模式不暴露该文件。


依赖下载与通用持久缓存（显式授权）：扩展上述 Go 离线缓存约定，新增 `exec_go_proxy` / `--exec-go-proxy` 设置 GOPROXY；默认仍为 off，且网络策略独立，下载必须显式开启 host 网络。新增语言无关的 `exec_caches` / `--exec-cache`，以名称、宿主专用绝对目录及环境变量列表描述缓存；宿主目录可写挂载到 `/run/caches/<name>`，环境变量指向该路径。Go 使用 GOMODCACHE，pip/npm 等通过各自缓存变量接入，执行器无需按语言分支。缓存持久化由宿主目录承担，不随进程树清理；进程会话与同步执行共用此授权。缓存目录不能与 Workspace、系统或运行时目录、其他缓存重叠，不能授权整个 HOME；不允许覆盖执行器保留变量（GOMODCACHE 为专门支持的例外），也不允许与 exec_env 冲突。可写缓存内容对共享该目录的所有执行可见且可修改，不作为可信运行时。未配置持久缓存时继续使用只读宿主 Go 模块缓存，GOSUMDB=off 与 GOTOOLCHAIN=local 保持不变。此项授权不提供缓存配额或自动回收。

host 网络模式同时只读挂载存在的系统公开 CA 证书目录（`/etc/ssl/certs`、`/etc/pki/tls/certs`、`/etc/pki/ca-trust/extracted`），供 Go 代理等 HTTPS 请求验证证书；不挂载私钥目录或整个 `/etc`。
