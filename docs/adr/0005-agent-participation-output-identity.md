# 按代理参与实例归属输出

多代理场景下同名节点可以接受多次独立委派，而一次委派又可能包含多轮执行，因此输出归属采用代理参与实例的稳定身份，父关系指向具体参与实例，主代理也拥有明确身份。不同委派分别展示，同一委派内的多轮执行与恢复延续原身份，避免按节点名混合输出或按执行轮次拆散同一个子代理。代理参与实例身份随运行检查点保留；实时层级与状态事件通过 Redis Stream 传递，补读受 Stream 保留时间限制。

输出生产链路只将事件写入 Redis Stream，不将输出事件写入 MySQL，SSE 订阅只读取和推送事件。Redis 写入失败返回错误并停止后续执行。该选择减少数据库写入和订阅链路耦合，但不提供 Stream 过期后的完整事件历史。运行与工具调用快照仍独立持久化，用于恢复和会话查询；归属字段贯穿 Redis/SSE，无历史数据兼容要求。
